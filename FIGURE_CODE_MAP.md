# Manuscript-to-code map

This table identifies the deposited program or data source for the principal
computational results in *Chimera states in a network of firefly oscillators*.

| Manuscript result | Reproduction entry point | Deposited output |
|---|---|---|
| Heterogeneous-delay simulations and full diagnostics | `CHIMERA_MODE=paper julia --project=. scripts/paper.jl` | `results/natural_chimera_case_*.png` and matching `*_gnuplot_data/` directories |
| Collective flash count and detected chorus | `scripts/paper.jl` | `results/natural_chimera_case_01_gnuplot_data/panel_02_flash_count.dat` and `panel_02_chorus_peaks.dat` |
| Cycle-resolved delay map | `scripts/paper.jl` | `results/natural_chimera_case_01_gnuplot_data/panel_10_cycle_delay.dat` |
| Delay covariance map and spatial covariance | `scripts/paper.jl` | `panel_19_delay_covariance_matrix.dat` and `panel_20_delay_covariance_vs_distance.dat` in the same directory |
| Role raster and character probability | `scripts/paper.jl` | `panel_13_role_raster.dat`, `panel_11_character_probability.dat`, and `panel_16_role_switch_count.dat` |
| Settle-kick attractor test | `julia --project=. scripts/settle_kick_attractor_figure.jl` | `figures/settle_kick_attractor/` |
| Exact published-case numerical check | `julia --project=. scripts/validate_exact_case.jl` | Console pass/fail report; expected values are recorded in `REPRODUCIBILITY_NOTES.md` |
| Event-resolved reduced-model identification | `julia --project=. scripts/model_validation.jl` | `figures/model_validation/` |
| Analytical normal-form checks | `julia --project=. scripts/analytical_validation.jl` | `figures/analytical_validation/` |
| Distributed-delay and characteristic-root checks | `julia --project=. scripts/distributed_delay_validation.jl` | `figures/distributed_delay_validation/` |

The uniform-delay chimera panels use legacy simulation outputs included with
the manuscript source and are not regenerated by the heterogeneous-delay
package. This limitation should remain explicit in the archive unless their
generation code is added before release.
