# Code availability

Use the following text in the manuscript after replacing the placeholders:

> **Code availability**  
> The Julia source code used to perform the simulations, analyse the results,
> and generate the figures reported in this study is openly available on
> Zenodo at https://doi.org/REPLACE_WITH_ZENODO_DOI. The development version
> is available at REPLACE_WITH_GITHUB_REPOSITORY_URL.

The Zenodo software record should also be cited in the reference list. Use the
exact citation exported by Zenodo after the `v1.0.0` GitHub release is archived.

Before release, replace the repository placeholder in `CITATION.cff`. After
Zenodo creates the DOI, replace the DOI placeholder above and add the DOI to
`CITATION.cff` as `doi: "10.5281/zenodo.XXXXXXX"`.
